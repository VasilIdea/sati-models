# sati-models

Файлы локальных ИИ-моделей приложения «Сати» (доставка — через
GitHub Releases этого репозитория, зеркало — HuggingFace).
Манифест с размерами и контрольными суммами: versions.json.

Модели качаются приложением только по Wi-Fi (по умолчанию),
данные не покидают телефон. Лицензии весов — Apache 2.0.
